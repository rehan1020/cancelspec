# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting feature on this repository, or by email to security@cancelspec.org.

## Response goals

- Acknowledge within 48 hours.
- Initial assessment within 7 days.
- Fix or mitigation plan within 30 days for confirmed vulnerabilities.

## Scope

- The CancelSpec website and scanner tool
- The build and release pipeline
- The playbook data format and validation

## Out of scope

- Third-party hosting infrastructure (Cloudflare, GitHub)
- Vulnerabilities in browsers themselves
