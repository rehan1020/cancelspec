# Governance

## Roles

### Contributor
Anyone who submits a pull request that is merged.

### Reviewer
A contributor who has had five playbooks merged with no accuracy problems. Reviewers can approve playbook pull requests.

### Region Maintainer
A reviewer responsible for playbooks in a specific region. Region maintainers can merge playbook pull requests for their region.

### Project Maintainer
Responsible for the codebase, releases, and overall project direction.

## Decision making

- Day-to-day decisions are made by the project maintainer.
- Significant changes are proposed through public issues or RFCs.
- No relicensing without a public RFC and notice to all contributors.

## Code of Conduct

All participants must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
