# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting feature on this repository (https://github.com/rehan1020/cancelspec/security/advisories/new), or by email to the security address specified in `project.config` (cancelspec@protonmail.com).

We appreciate responsible disclosure and acknowledge reports within 48 hours.

## Response Goals

- **Acknowledge**: within 48 hours.
- **Initial Assessment**: within 7 days.
- **Mitigation/Fix**: within 30 days for confirmed vulnerabilities.

## Scope

- CancelSpec web application and statement scanner tool
- Core matching engine and Web Worker pipeline
- Build and release distribution workflows
- Playbook schema and validation tooling
